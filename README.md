# Aquarium Co-Op Transcript Search

An unofficial, non-commercial search index of Aquarium Co-Op's YouTube videos and livestreams.
Search a product, fish, plant, or phrase and jump to the exact moment in the original video.

- Text comes from YouTube's auto-generated captions, with misheard product, fish, and plant names corrected.
- Every result links back to the original video on YouTube.
- Not affiliated with or endorsed by Aquarium Co-Op.

Open `index.html` (or the GitHub Pages site) to search. The transcript data lives in the `data` folder, one file per year.
